# Privacy Policy

WhoSpoke does not collect, store, sell, or transmit personal data.

The extension uses the Chrome tabs permission only to detect tabs that are currently playing audio and to allow the user to switch to, mute, unmute, or close those tabs.

Tab information is used locally in the browser while the popup is open. It is not sent to any external server and is not stored by the extension.

WhoSpoke does not use analytics, advertising, tracking, or remote code.
