# Chrome Web Store Listing

## Korean

### Name

누가 소리를 내었는가?

### Short Description

소리 나는 탭을 찾아 이동, 음소거, 닫기를 빠르게 할 수 있는 Chrome 확장 프로그램입니다.

### Detailed Description

수십 개의 Chrome 탭 중 어떤 탭에서 소리가 나는지 바로 확인하세요. WhoSpoke는 현재 소리를 내는 탭을 모아 보여주고, 해당 탭으로 이동하거나 음소거하거나 닫을 수 있게 도와주는 작은 Chrome 확장 프로그램입니다.

주요 기능:

- 소리 나는 탭 목록 표시
- 탭 제목, 도메인, 파비콘 표시
- 클릭 시 해당 탭과 창으로 이동
- 탭 단위 음소거/음소거 해제
- 탭 닫기
- 현재 재생 중인 탭 전체 음소거
- 툴바 배지에 재생 중인 탭 개수 표시

WhoSpoke는 광고, 추적, 분석 도구를 사용하지 않습니다. 탭 정보는 팝업이 열려 있는 동안 브라우저 안에서만 사용되며 외부 서버로 전송되지 않습니다.

## English

### Name

Who made that sound?

### Short Description

Find noisy Chrome tabs and quickly switch to, mute, or close them.

### Detailed Description

Instantly find which Chrome tab is making sound. WhoSpoke lists the tabs currently playing audio so you can jump to the right tab, mute it, unmute it, or close it without hunting through every open window.

Key features:

- Shows tabs that are currently playing audio
- Displays each tab's title, domain, and favicon
- Opens the selected tab and focuses its window
- Mutes or unmutes individual tabs
- Closes noisy tabs
- Mutes all currently playing tabs at once
- Shows the number of playing tabs in the toolbar badge

WhoSpoke does not use ads, tracking, analytics, or remote code. Tab information is used locally in your browser while the popup is open and is never sent to an external server.
